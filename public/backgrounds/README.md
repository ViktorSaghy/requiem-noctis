# Backgrounds

Full-bleed scene/location images. Displayed in the game header and on the title screen.

## Naming convention

| File | Used by |
|------|---------|
| `background-splash.png` | Title screen, Story Select card, game fallback |
| `act1-vienna-streets.png` | Act 1 scenes (exploration) |
| `act2-elysium.png` | Act 2 scenes (tension) |
| `act3-warehouse.png` | Act 3 scenes (tension/combat) |
| `act4-final.png` | Act 4 / combat scenes |

## Specs

- **Resolution:** 1920×1080 minimum (16:9). Portrait crops (1080×1920) work well on mobile.
- **Format:** PNG or WebP
- **Size:** keep under 500 KB per file (WebP strongly recommended)
- The game overlays a dark gradient on top, so dark moody images work best.
