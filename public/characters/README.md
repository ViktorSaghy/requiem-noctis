# Character Art

Portrait images for player characters and NPCs.

## Naming convention

| File | Used by |
|------|---------|
| `portrait-ventrue.png` | Ventrue clan default portrait |
| `portrait-toreador.png` | Toreador clan default portrait |
| `portrait-malkavian.png` | Malkavian clan default portrait |
| `portrait-nosferatu.png` | Nosferatu clan default portrait |
| `portrait-brujah.png` | Brujah clan default portrait |
| `portrait-tremere.png` | Tremere clan default portrait |
| `portrait-gangrel.png` | Gangrel clan default portrait |
| `portrait-lasombra.png` | Lasombra clan default portrait |
| `npc-kessler.png` | NPC: Kessler |
| `npc-vasile.png` | NPC: Vasile |
| `npc-miriam.png` | NPC: Miriam |

## Specs

- **Resolution:** 512×512 or 512×768 (portrait aspect)
- **Format:** PNG (transparent background optional) or WebP
- **Size:** keep under 200 KB per file
