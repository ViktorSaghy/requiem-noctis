# UI Assets

Decorative UI elements: borders, clan sigils, dividers, icons.

## Naming convention

| File | Used by |
|------|---------|
| `sigil-ventrue.svg` | Ventrue clan icon |
| `sigil-toreador.svg` | Toreador clan icon |
| `sigil-malkavian.svg` | Malkavian clan icon |
| `sigil-nosferatu.svg` | Nosferatu clan icon |
| `sigil-brujah.svg` | Brujah clan icon |
| `sigil-tremere.svg` | Tremere clan icon |
| `sigil-gangrel.svg` | Gangrel clan icon |
| `sigil-lasombra.svg` | Lasombra clan icon |
| `border-ornate.png` | Decorative panel border |
| `divider.svg` | Section divider line |

## Specs

- **Sigils:** SVG preferred (scales cleanly at any size)
- **Decorative PNG:** keep under 50 KB
